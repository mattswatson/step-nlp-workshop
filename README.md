# STEP NLP Workshop

A hands-on introduction to Natural Language Processing (NLP). Little-to-no coding experience required. 
Build simple versions of the ideas behind modern AI language models — and see where those ideas work and where they break. 

## Contents

- **`01_STEP_BoW_and_Similarity.ipynb`** — *Teaching a computer to read sentiment.* Compares a rule-based classifier (counting "good" and "bad" words) with a simple "meaning" model built from word-count vectors, then explores where each gets fooled — negation, sarcasm, and unfamiliar words.
- **`02_STEP_Tokenisation_and_Generation.ipynb`** — *How an AI actually writes.* Covers tokenisation (turning text into numbers, including sub-word chunks) and builds a tiny next-word predictor that generates its own text — the same core idea as ChatGPT.
- **`STEP NLP Workshop.pptx`** — Presentation slides.
- **`STEP NLP Workshop Worksheet.docx`** — Accompanying worksheet, the first activity.

## Running the notebooks

The two notebooks use only the Python standard library, so they run anywhere Jupyter is available.

Open a notebook and run the cells **in order, top to bottom**. If you hit an error, re-run the cell above it and try again.
